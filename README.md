# Kaixo

Aplicació mòbil per aprendre euskera de manera fàcil, ràpida i divertida.

## Objectiu

Sessions curtes de 5–7 minuts per avançar des del nivell A1 fins al B1.

## Nivells

- A1 — Inicial
- A2 — Intermedi
- B1 — Intermedi avançat

## Progrés

L'aplicació guardarà el progrés de l'usuari, els punts i les ratxes de dies consecutius.

## Estat

🚧 Desenvolupament inicial.
